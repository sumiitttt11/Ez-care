# Ez-Care 🚀  
Ez-Care is an on-demand service platform, similar to Urban Company, designed to connect users with professionals for various home and personal services. It offers:  
- ✅ Seamless service booking  
- ✅ Real-time service tracking  
- ✅ Secure payments  
- ✅ Efficient and scalable architecture  

## 🏗 Tech Stack  
- **Frontend**: React.js
- **Backend** : Soon   

## 🚀 Features  
- Browse & book home services  
- User & service provider dashboards  
- Payment gateway integration  
- Real-time notifications  

## ⚡ Getting Started  

### Prerequisites  
Ensure you have the following installed:  
- **Node.js** 
- **npm** or **yarn**  

### 🛠️ Setup Instructions  

#### 1️⃣ Clone the Repository  
```sh
git clone https://github.com/sumiitttt11/Ez-care.git  
cd ez-care
```
#### 2️⃣ Install Dependencies
```sh
npm install
```
#### 3️⃣ Run Project 
```sh
npm start
```
#### 4️⃣ That's it:
```sh
The application will be running at http://localhost:3000.
```
